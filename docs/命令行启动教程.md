# 命令行手动启动教程

Windows 本机手动启动校园委托平台（前后端分离 monorepo）的完整步骤。均经本机实测。

## 0. 前置依赖

| 组件 | 位置 / 要求 |
|---|---|
| JDK | `D:\soft-tools\.jdks\jdk-21`（项目 target Java 8，本机 JDK 21 可编译） |
| Maven | `D:\soft-tools\apache-maven-3.6.3`（`mvn` 已在 PATH） |
| Node/npm | `D:\soft-tools` 下的 nvm/Node |
| MySQL | `localhost:3306`，库 `campus_entrustment`，root/1234 —— **必须已启动**（后端连不上会起不来） |
| Redis | `D:\soft-tools\redis`（可选；后端惰性连接，未启动也能起来，只是缓存/通知功能不可用） |

Maven 生效配置：全局 `D:\soft-tools\apache-maven-3.6.3\conf\settings.xml`，本地仓库指向 `D:\CODE\mvn_repository`（阿里云镜像）。另有一份规范配置 `D:\soft-tools\.m2\settings.xml`（仓库 `D:\soft-tools\.m2\repository`），默认不生效，需 `-s` 显式指定。

## 1. 启动后端（二选一）

**方式 A：开发模式（源码直接跑，适合改代码）**

```bash
# 工作目录必须是仓库根（含 pom.xml）
mvn spring-boot:run
```

**方式 B：打包后用 jar 跑（生产/重启场景）**

```bash
mvn clean package -DskipTests            # 生成 target/campus_entrustment-1.0-SNAPSHOT.jar
java -jar target/campus_entrustment-1.0-SNAPSHOT.jar
```

两种方式都读取 `application.yml`（默认激活 `dev` profile），端口 80、上下文 `/campus_entrustment` 来自 gitignored 的 `application-dev.yml`（已打进 jar）。

## 2. 启动前端

```bash
cd web
npm run serve          # 首次运行先 npm install
```

dev server 端口 8080，`/api` 代理到 `localhost:80` 并 rewrite `/api`。

## 3. 验证与访问

```bash
# 后端是否在线：返回 401 表示正常（Spring Security 拦截未带 token 请求）
curl -s -o /dev/null -w "%{http_code}" http://localhost:80/campus_entrustment/
```

- 前端页面：`http://localhost:8080`
- 后端接口：`http://localhost:80/campus_entrustment`（白名单外接口需 `jwt` 请求头）
- API 文档：`http://localhost:80/campus_entrustment/doc.html`
- 日志：`logs/server.log`（后端）、前端 dev server 终端输出

## 5. 常见坑

1. **工作目录陷阱**：`cd web` 后命令行工作目录停在 `web/`，再跑 `mvn` / `git` 会报「无 POM / pathspec 不匹配」。跨目录操作先 `cd` 回仓库根。
2. **端口被占**：后端 80 / 前端 8080 被占用时启动直接报错。查占用：`netstat -ano | findstr :80`。
3. **MySQL 没启动**：后端报 `Cannot create PoolableConnectionFactory` / `Communications link failure`，先启动 MySQL。
4. **Maven 依赖下载失败**：`D:\CODE\mvn_repository` 缓存 + 阿里云镜像；github 443 偶发连不上可重试。
